The Project

A university's Creative Industries Festival needed a real booking system — not a mockup. Attendees needed to browse events, book a spot, and get a scannable entry pass. Organisers needed a dashboard to manage events and see who'd booked what, without touching code. I built both sides of that, backed by a shared Firebase database.

Live event browsing — filterable by day & category, synced from the admin panel in real time
Digital entry pass — generated the moment a booking is confirmed

What I Built

Booking system with real data integrity
Built around Firestore atomic transactions, so a capacity check, booking creation, and attendee-count update all succeed or fail together — no overbooking, even under concurrent requests.
Guest access with real restrictions
A separate guest mode: visitors browse freely, but booking or viewing a profile prompts account creation — enforced at the navigation level, not just hidden buttons.
Admin panel organisers actually use
A React dashboard with live stats, a bookings manager, and a content editor — non-technical staff update the homepage and manage bookings with no deployment needed.
Automated testing across both apps
Playwright for the web admin panel, Maestro for the mobile app — end-to-end tests walking through the real booking flow, catching regressions before real users would.
Built for release, not just for demo
Configured EAS Build for internal test distribution and prepared the app for App Store / Google Play submission.
Live-managed content, no redeploy needed
Hero banner, highlights, and event details all pull live from Firestore — an admin edits content and it updates in the app instantly.

Problem-Solving, Not Just Building

Native crash affecting the whole team
Traced a startup crash to a native module loaded too early, and fixed it by lazy-loading it only when actually used — no lost functionality.
Corrupted dependency file
Found the app's package.json mixed up with an unrelated backend project, missing core dependencies entirely. Rebuilt it and verified with a clean install.
Silent data-sync bug
Diagnosed a missing Firestore composite index causing events to vanish from the home screen with no visible error, and resolved it at the database layer.
